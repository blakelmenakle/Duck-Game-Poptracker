# DuckGame Tracker for Archipelago

## Features

* Items Tracking
* Level Unlock Tracking
* Medal Settings
  * Select which medals are available as checks (Defaults to on)

## Installation

Download the latest release from the releases section, and then move it into `/poptracker/packs/` and you're all set!

PopTracker v0.35.4 or higher is recommended.
